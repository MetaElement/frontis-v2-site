# Frontis 官网发布差异说明 20260524-235606

本文面向运维部署工程师，用于说明本次发布包相对以下基线版本的变化：

- 基线包：`frontis-website-cta-20260519-001826.zip`
- 基线 SHA256：`6fc5b87f16193b47a7a37c82ee3c067262e5ba327ad0d84447faa4c708e57e70`
- 本次发布包：`frontis-website-cta-seo-gtm-ga4-beian-scene-20260524-235606.zip`

## 1. 发布目标

本次版本在 20260519 CTA 基线之上，补齐 SEO、Google Tag Manager / GA4、备案展示、生态页和场景页内容调整，并保留 CTA 表单的生产部署能力。

GitHub Pages 已作为静态预览发布通道：

```txt
https://metaelement.github.io/frontis-v2-site/
```

注意：GitHub Pages 只托管静态页面，不运行 `/api/cta`。生产环境如需 CTA 表单正常提交，仍需按 `docs/ops-cta-config.md` 使用 Node 服务和 Nginx 反向代理部署。

## 2. 与基线包相比的主要变化

### SEO

- 新增集中式 SEO 生成脚本：`scripts/seo-pages.mjs`、`scripts/apply-seo.mjs`。
- 所有 12 个公开页面补齐 title、description、canonical、Open Graph、Twitter Card 和 JSON-LD。
- 新增并打包 `robots.txt`、`sitemap.xml`。
- 新增默认社交分享图：`assets/og-frontis.svg`。
- `scripts/check-site.mjs` 已扩展为检查页面、SEO metadata、sitemap、robots 和静态资源。

### 数据跟踪分析

- 所有公开页面安装 Google Tag Manager：`GTM-K3FKM238`。
- 新增 `components/analytics-config.js`、`components/analytics.js`。
- 当前 GA4 Measurement ID：`G-0C4VHZ14XL`。
- 当前策略是 GTM 负责 GA4 页面访问上报，前端直接 GA4 上报保持关闭：

```js
enableDirectGa4: false
```

- 前端向 `dataLayer` 推送 CTA 点击、CTA 提交、`generate_lead`、导航点击、邮箱点击和站外链接点击等事件。
- 前端分析事件不发送姓名、手机号、邮箱、公司名和留言正文。
- 详细配置见 `docs/analytics-config.md`。

### CTA 和后端部署

- `api/cta.js` 增强了 CTA 提交链路，支持 SMTP 邮件通知、飞书群机器人通知、来源校验、字段校验和失败兜底。
- 新增本地和生产服务脚本：
  - `scripts/local-cta-server.mjs`
  - `scripts/serve-production.mjs`
  - `scripts/test-cta-api.mjs`
- `.env.example` 补齐 SMTP、飞书、允许来源和运行端口等生产变量模板。
- `package.json` 新增 `start`、`dev:full`、`test:cta` 等脚本。
- CTA 生产部署仍以 `docs/ops-cta-config.md` 为准。

### 备案和合规展示

- 页脚在原 `京ICP备2022014486号-1` 基础上新增：

## 5. 运维部署注意事项

1. 如果部署到生产服务器并需要 CTA 表单可用，请部署本包中的 `dist/`、`api/`、`scripts/`、`package.json`、`package-lock.json` 和 `.env.example`，并按 `docs/ops-cta-config.md` 配置 `.env.production`。
2. 如果只做静态托管，可以只部署 `dist/`，但 CTA 表单提交接口不可用。
3. GTM 后台已经配置 GA4 All Pages 标签时，保持 `components/analytics-config.js` 中 `enableDirectGa4: false`，避免重复 page_view。
4. 生产部署后建议用 GTM Preview / Tag Assistant 验证 `GTM-K3FKM238`、`G-0C4VHZ14XL` 和 CTA 事件。
5. 上线后验证：

```bash
curl -I https://frontis.cn/
curl -I https://www.frontis.cn/
curl -I https://frontis.cn/sitemap.xml
curl -I https://frontis.cn/robots.txt
```

如启用 CTA Node 服务，再执行 `docs/ops-cta-config.md` 中的 `/api/cta` POST 联调命令。

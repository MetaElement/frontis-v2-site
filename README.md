# Frontis V2 Website

High-fidelity static implementation of the Frontis public website prototype.

## Pages

- `index.html`
- `horizon.html`
- `leadeep.html`
- `scene.html`
- `scene-strategy.html`
- `scene-supply.html`
- `scene-sales.html`
- `scene-ops.html`
- `scene-research.html`
- `technology.html`
- `ecosystem.html`
- `about.html`

## Run

```bash
npm install
npm run dev
```

The site is also fully static, so `index.html` can be opened directly in a browser.

## Build

```bash
npm run build
```

## Check

```bash
npm run check
```
